# Aryan Pandey - Developer Portfolio

A fast, distinctive portfolio built for a full-stack developer applying for internships.
Built with Vite, React, and plain CSS tokens (no UI frameworks).

## Setup & Running

1. **Install dependencies**
   ```sh
   npm install
   ```

2. **Run local development server**
   ```sh
   npm run dev
   ```

3. **Build for production**
   ```sh
   npm run build
   ```

## Deployment Steps

This project can be easily deployed to **Vercel** or **Netlify**:

### Vercel
1. Create a Vercel account and link your GitHub.
2. Import the `aryan-portfolio` repository.
3. Vercel will automatically detect Vite and set the build command to `npm run build` and the output directory to `dist`.
4. Click **Deploy**.

### Netlify
1. Create a Netlify account and link your GitHub.
2. Import the `aryan-portfolio` repository.
3. Set the Build Command to `npm run build` and the Publish Directory to `dist`.
4. Click **Deploy Site**.
